# Semana 8 - Ciencia de Datos

## Análisis de datos de AquaLimpia S. A.

Este repositorio contiene el desarrollo práctico correspondiente a la Semana 8 de la asignatura Ciencia de Datos. El análisis se realiza sobre un conjunto de datos de AquaLimpia S. A., relacionado con la operación de plantas de tratamiento de aguas residuales.

## Objetivo

El objetivo del análisis es explorar el comportamiento de las principales variables operacionales, comparar el desempeño entre plantas y generar información que facilite la interpretación de los datos.

Para ello se utilizan técnicas de análisis exploratorio de datos y visualización mediante Python.

## Dataset

El archivo `dataset_set_A_aguas_residuales.xlsx` contiene 200 registros y variables asociadas a la operación de las plantas, entre ellas:

- Planta.
- Caudal de entrada.
- DBO de entrada.
- SST de entrada.
- pH de entrada.
- Energía de aireación.
- Lodos generados.
- DBO de salida.
- Cumplimiento de la norma.

## Análisis realizado

Durante el desarrollo se realizaron las siguientes actividades:

- Carga y exploración inicial del dataset.
- Revisión de dimensiones, tipos de datos y valores nulos.
- Obtención de estadísticas descriptivas.
- Cálculo de la eficiencia de remoción de DBO.
- Comparación del desempeño entre plantas.
- Análisis del cumplimiento normativo.
- Elaboración de visualizaciones para apoyar la interpretación de los resultados.
- Construcción de un dashboard exploratorio con indicadores operacionales.
